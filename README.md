# Steps to clone

1. create a folder on your computer and `cd` into it


2. clone the project with the following command:
```bash
git clone https://github.com/omarakamal/fruits-starter.git .
rm -rf .git
rm README.md
```

3. Create a `.env` file and add your mongodb connection string like so:

```
MONGODB_URI=your-connection-string

```


4. run `npm i` in your terminal
```
npm i
```
